# Atividade — Primeira Avaliação: Programação para Frameworks Web

Atividade individual da disciplina de Programação de Frameworks Web.

## Requisitos desenvolvidos

- Ordenação e contagem total de alunos
- Busca de aluno por ID utilizando `findUnique`
- Atualização de aluno utilizando `update`
- Remoção de aluno utilizando `delete`

## Tecnologias

- Node.js
- Express
- Prisma
- MySQL

## Rotas implementadas

```text
GET    /alunos
GET    /alunos/:id
PUT    /alunos/:id
DELETE /alunos/:id
